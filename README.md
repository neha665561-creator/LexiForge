# LexiForge

Welcome to LexiForge! I built this full-stack web application to create an immaculate, fast, and highly efficient workspace for prompt engineering. Instead of clunky interfaces, LexiForge gives developers a modern environment to craft, optimize, test, and evaluate complex AI prompts seamlessly.

# Tech Stack & Engineering Choices
* **Framework:** TanStack Start (Full-stack React with file-based routing for rapid navigation)
* **Language:** TypeScript (Strict typing to ensure reliable prompt manipulation and data states)
* **Runtime/Package Manager:** Bun (Chosen for ultra-fast compilation and dependency management)
* **Styling:** Tailwind CSS & Shadcn UI (Component-driven design for an immaculate, modern developer experience)

# Key Features Implemented
* **Prompt Composer & Optimization Engine:** A dedicated workspace to draft, version, and refine complex system prompts.
* **Evaluations & Metrics Panel:** Real-time feedback panels and scoring metrics to benchmark prompt outputs.
* **API Reference View & History Sidebar:** Designed for quick developer integration and historical tracking of prompt generations.
